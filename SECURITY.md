# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository:

https://github.com/DustinEwan/lintel/security/advisories/new

Do not open a public issue for a suspected vulnerability. Include the affected
version, reproduction steps, and impact. If a finding relates to a semantic
decision, include the fingerprint rather than private project source.

## Supported versions

Only the latest released version receives security fixes. Pre-release builds
are supported only while they are the current recommended build.

## Scope

Lintel reads source files and policy files from the repository it checks. It
does not execute project code. Reports about unsafe paths, unintended writes,
credential exposure, or malformed fact files are in scope.
